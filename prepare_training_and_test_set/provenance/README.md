# Tracked PinMyMetal Split Provenance

These files are byte-for-byte copies of lightweight generated metadata from
the Git-ignored exact and Common-PDBID 70/30 dataset roots. Original PinMyMetal
membership remains authoritative in `pinmymetal_files/`, while these snapshots
record how available supported structures were projected and repartitioned.

- `exact/` records the possibly-overlapped supported-structure projection.
- `common_pdbid_70_30/` records the custom seed-42 whole-PDB assignment.

Non-overlapped and harsh generated roots were not present locally during this
snapshot. Their construction scripts remain tracked, and their availability is
recorded in `docs/DATASETS.md`.

`SHA256SUMS` records copied-file hashes.
