# Remote homology validation reuse — portable evidence

These are byte-identical copies of selected outputs under
`DeepMzyme_Data/notebook_outputs/remote_homology_v1/`. The
[summary](../../summaries/summary_remote_homology_v1_20260917.md) explains their
meaning; the [addendum](../../../REMOTE_HOMOLOGY_ADDENDUM.md) owns the protocol.
`SHA256SUMS` verifies the copied artifacts, including the closeout receipt.
Descriptive Markdown in this README is not part of that checksum inventory.

- `protocol.json`, reuse ledgers and preparation reports bind scope and source
  identities. The full-protein readiness report records the unresolved gates.
- `counts_freeze.json` and `remoteness_manifest.json` were frozen before
  prediction joins; both coverage rules keep no-hit cases unclassified.
- Per-task search receipts/logs record the pinned binary, arguments, input and
  output hashes. The failed initial 1 GiB EC request remains separately labeled.
- `predictions/` contains all twelve validated exports and their receipts;
  group-level EC predictions average logits. Manifest generations retain the
  initial one-run probe and subsequent twelve-run index.
- `reports/metal/` and `reports/ec/` contain the separate full-vocabulary
  reports. The primary interaction is unestimable, not zero.
- `exporter_source_audit.json` and `exporter_sources/` preserve the one
  operational-source provenance correction described in the summary. Original
  prediction receipts were not rewritten.
- `runtime_reconciliation/` records exactly-once import of the closed host-only
  interval; `runtime_release1_source/` describes the offline source snapshot.
- Test logs and `closeout_verification.json` record completed checks.

Checkpoints, feature caches, frozen model-source archives, full sequences and
alignment TSVs remain in ignored local storage. Absolute paths in original
receipts are preserved as evidence and require explicit remapping elsewhere.
This package does not claim to redistribute the full checkpoint/data package.
No new training, GPU allocation, held-out evaluation or model promotion is
part of this batch. The existing GPU campaign remains paused.
